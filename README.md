### Como colocar no GitHub
1. Extraia o ZIP no computador. Abra a pasta `Exercicios_ML_UDF`.
2. Crie um repositório na sua conta com o nome `aprendizado-maquina-udf`.
3. No repositório, use **Add file > Upload files**. Envie o conteúdo da pasta, incluindo as subpastas. O `README.md` deve ficar na raiz do repositório.
4. Registre um commit: `Adiciona modelos das atividades do módulo IV - Rafael Mota`.
5. Abra cada `.md`, edite com as suas respostas e confirme os commits.
6. No Colab, execute o notebook, salve em `notebooks/laboratorio-equipe.ipynb` e suba no repositório.
7. Atualize os links das evidências e envie o link do repositório na plataforma da professora.
